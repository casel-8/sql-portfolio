
# SQL Portfolio — Zalsha

Welcome to my SQL portfolio!

This repository showcases practical SQL examples using fictional datasets. It demonstrates my skills in querying, analyzing, reporting, and managing relational database data using MySQL and PostgreSQL.

The projects are designed to demonstrate practical database skills through simple business scenarios.

## About Me

I have hands-on experience with relational databases through academic projects and database-related learning activities.

I am interested in small, clearly defined tasks involving SQL query writing, data retrieval, basic reporting, and database support.

## Technical Skills

- **SQL:** SELECT, WHERE, JOIN, GROUP BY, HAVING, subqueries, aggregate functions
- **Data Manipulation:** INSERT, UPDATE, DELETE
- **Database Design:** Primary keys, foreign keys, table relationships, normalization
- **Reporting:** Sales summaries, revenue calculations, transaction analysis
- **Tools:** MySQL, PostgreSQL, DBeaver, Git, GitHub

## Portfolio Projects

### 01. SQL Query Practice

**Folder:** `01-query-practice/`

**File:** `sales_queries.sql`

A practical exercise using a fictional online store dataset.

Topics covered:
- Retrieving and filtering records
- Sorting query results
- INNER JOIN and LEFT JOIN
- GROUP BY and aggregate functions
- Subqueries

**Objective:** Practice retrieving and combining relational data to answer common business questions.

---

### 02. Sales Data Reporting

**Folder:** `02-data-reporting/`

**File:** `sales_report.sql`

A collection of SQL queries designed to generate basic sales reports from transaction data.

Topics covered:
- Total transaction calculations
- Revenue summaries
- Sales analysis by customer city
- Monthly sales reports
- HAVING and aggregate filtering

**Objective:** Transform transaction data into meaningful summaries that can support basic business reporting.

---

### 03. Relational Database Design

**Folder:** `03-database-design/`

**File:** `database_design.sql`

A simple bookstore database designed to demonstrate relational database structure and relationships.

Topics covered:
- Table creation using CREATE TABLE
- Primary keys and foreign keys
- Data integrity constraints
- Table relationships
- Multi-table JOIN queries

**Objective:** Demonstrate the fundamentals of designing and querying a relational database.
